# NYC Parking and Camera Violation Search

## Introduction

The **[NYC Parking and Camera Violation Search](https://nycparkingandcameraviolation.vercel.app/)** is a web application that allows users to search for any tickets a driver has recieved within New York City. Users can type in the license plate they want to look up, and the page will display various relevant information, including the summons number, date of issue, county, violation details, fine amount and amount due.

We created this app in hopes that it will help users to easily navigate and find information on tickets they have received in the past.

## How to use this repo

First `cd` into the `src` file, and then use `npm i` to install dependencies. `npm run dev` can be used to start the local server.

## Tech stack

Main technology stacks used for this project include Socrata, NextJS, Tailwind. The data comes from the [NYC Open Data](https://opendata.cityofnewyork.us/).
